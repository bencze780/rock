Szoftverfejlesztő Szakmai Vizsga

Projektfeladat B: Asztali- és Webes Szoftverfejlesztés

⏱️ Időtartam: 240 perc 📅 Dátum: 2025. május 20. 🏆 Összpontszám: 65 pont

A vizsgafeladat célja egy komplex szoftverrendszer megvalósítása, amely az 1970-es évek legendás rockzenekarainak adatait kezeli. A projekt során bizonyítanod kell tudásodat az adatbázis-kezelés, backend API fejlesztés, asztali alkalmazások (Console/GUI) és a reszponzív webfejlesztés területén.

15p

Node.js + MySQL

25p
Frontend Web

HTML, CSS, JS/React

25p
Asztali App

Console + GUI

Pontszámok Eloszlása

Az alábbi diagram szemlélteti, hogyan oszlanak meg az elérhető pontok az egyes részfeladatok között. Látható, hogy a webes fejlesztés (Backend + Frontend) teszi ki a vizsga súlypontját.

Adatbázis Szerkezet

A rendszer alapja a rock_zenekarok_70s adatbázis. A kapcsolat típusa 1:N (Egy stílushoz több zenekar tartozik).

stilusok
🔑 id (PK) int
stilus_neve varchar
zenekarok
🔑 id (PK) int
nev varchar
🔗 stilus_id (FK) int
orszag / varos varchar
aktiv_evek varchar
kep_url text

Backend API (Node.js)

A szervernek REST API végpontokon keresztül kell kiszolgálnia a kéréseket. A válaszok formátuma minden esetben JSON.

Metódus Végpont Leírás
GET /zenekar Összes zenekar listázása teljes adattartalommal.
GET /stilusok Zenei stílusok listája (legördülő menühöz).
POST /ujzenekar Új zenekar felvétele. Siker esetén 201 Created.
DELETE /zenekartorlese Zenekar törlése ID alapján.

Frontend Logika
